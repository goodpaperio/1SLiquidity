# v1.0.9 Protocol Upgrade Plan

## Scope

Upgrade routing and deployment flow to improve quote reliability across token pairs by:

- Expanding Uniswap V3 coverage to all key fee tiers (`100`, `500`, `3000`, `10000`)
- Keeping quote-aware stream planning in `StreamDaemon.evaluateStreamPlan(...)`
- Hardening StreamDaemon DEX-to-router registration for production operations
- Providing one-command fresh deployment flow while keeping phased scripts as fallback

## Runtime Call Flow

```text
User/Bot
  -> Core.executeStream(tradeId)
      -> StreamDaemon.evaluateStreamPlan(tokenIn, tokenOut, amountRemaining, ...)
          -> Candidate fetchers:
             [V2, V3(100), V3(500), V3(3000), V3(10000), Sushi, ...]
          -> rank by reserve/price mode
          -> quote-validate candidates (fallback on failure)
          -> returns (bestFetcher, router, sweetSpot, streamVolume, quotedOut, quoteAux)
      -> Core computes amountOutMin from quotedOut/slippage
      -> Registry.prepareTradeData(...)
      -> Executor swap delegatecall
```
